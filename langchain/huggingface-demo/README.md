# LangChain + Hugging Face Chatbot

Gradio chatbot using LangChain and Hugging Face Inference Providers.

## Secrets

In **Settings → Secrets** add:

```
HF_TOKEN=hf_xxxxxxxx
```

Optional:

```
HF_MODEL=microsoft/Phi-3-mini-4k-instruct
```
